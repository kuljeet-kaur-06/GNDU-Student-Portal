# GNDU image placement

Place the two supplied original GNDU images in this folder using these exact filenames:

- `gndu-logo.jpeg` — the Guru Nanak Dev University emblem/logo.
- `gndu-campus.jpeg` — the GNDU campus building photograph.

The portal is already wired to both paths. The temporary visual placeholders automatically disappear after a browser refresh once the files are present. Keep the logo's original proportions; do not resize or crop the image file itself.
